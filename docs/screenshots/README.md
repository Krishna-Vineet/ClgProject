# CampusOps Demo Screenshots

These screenshots were captured from the running CampusOps web app using the repository's seeded **fictional demo data**. They contain no real student or staff records. The test environment used a local PostgreSQL database, `DEMO_MODE=true`, and disabled external file storage.

| File | Screen |
|---|---|
| `01-management-sign-in.png` | Public landing page and staff sign-in form |
| `02-admin-dashboard.png` | Administrator dashboard with demo event and activity summaries |
| `03-events.png` | Event list with seeded draft/approval/published/live/completed records |
| `04-approvals.png` | Faculty approval inbox with pending demo resource requests |
| `05-resources.png` | Resource catalogue with seeded rooms and equipment |
| `06-reports.png` | Report creation for the completed demo event |
| `07-administration.png` | Administration workspace with demo institution records |
| `08-report-preview.png` | Preview-only event report showing seeded approvals, resources and attendance |

The report preview is not filed as a permanent report. These images are illustrative review artifacts, not production data or evidence of a live institutional deployment.
